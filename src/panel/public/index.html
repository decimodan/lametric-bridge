          Alertas / cards

          Tarjetas prediseñadas y personalizadas. Elegí el reloj destino (incluidos varios Ulanzi) y enviá con un clic. En el API usá {"card":"paquete","device":"ulanzi"}.

          Crear card

          Slug único para el API. En el texto podés usar {{ state }}, {{ name }}, {{ unit }}.

          Automatizaciones (IF → THEN)

          Como IFTTT: fuente Conexiones (Sentinel / Frigate), Sensores o Home Assistant → card → reloj.

          SI

          Usa las condiciones del sensor (umbrales, intervalo) configuradas en Inicio → Sensores.

          ENTONCES

          Conexiones: el app del panel debe llamarse igual (sentinel, frigate). Vars Sentinel: {{ name }}, {{ hot_free }}, {{ text }}, {{ event }}. Vars Frigate: {{ label_es }}, {{ camera }}, {{ zone }}, {{ score }}. Sensores: vars {{ name }}, {{ title }}, {{ state }}, {{ unit }}, {{ entity_id }}.
