Relojes

LaMetric Time y Ulanzi (AWTRIX) conviven. Cada uno tiene un slug para identificarlo en notificaciones y en Home Assistant. Opcional: ligá cada reloj por MAC para redescubrir la IP si cambia en la LAN.

    Enviar notificación

    Vacío en destino = todos los relojes. En el API usá device con el slug.

    Alertas / cards

    Tarjetas prediseñadas y personalizadas. Elegí el reloj destino (incluidos varios Ulanzi) y enviá con un clic. En el API usá {"card":"paquete","device":"ulanzi"}.

    Biblioteca

    Presets + tus cards. Clic en Enviar → destino seleccionado arriba.

    Crear card

    Slug único para el API. En el texto podés usar {{ state }}, {{ name }}, {{ unit }}.
