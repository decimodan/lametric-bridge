# Problem definition

El objetivo de este software debe ser:

1. Tengo un reloj Lametric Time que servira para mostrar notificaciones e informacion de diferentes aplicaciones
2. Debe exponer una interfaz para poder conectar diferentes aplicaciones  
2.1 Las diferentes aplicaciones mandan datos, la responsabilidad de este puente es mostrarlos en el reloj
3. Debe tener un panel para poder configurar esta información
4. Las aplicaciones deben de poder configurar facilmente las notificaciones
5. Debe poder conectar información de Home Assistant (y elegir cual mostrar y como)
6. Todo debe configurarse desde WiFi
7. Considera que se montará como un aplicativo en Dokploy
8. Las aplicaciones que se conectan son de la red local
